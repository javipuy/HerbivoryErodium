# Script repository for "Multilayer plastic responses to ungulate experimental herbivory: phenotypic, hormonal, transcriptomic and epigenetic changes in *Erodium cicutarium*"

This repository contains the scripts needed to replicate the results 
from the data analysis from the aforementioned paper.

The repository includes this README.md file with instructions to execute 
all the scripts, besides the script with the actual analytical pipeline.

## Folder "RNAseq_analysis"

This folder contains all the scripts used to analyze the RNA-seq data,
from downloading the FASTQ files to generating figures and statistics.

The scripts are not fully automated. Thus, chunk by chunk execution is
recommended. In addition, the user has to set manually all the working 
directories before running any of the commands.

### 01-ecicHerb_RNA-seq_QC_trim_aln_pipeline.sh

This bash shell script performs the project directory configuration, the 
download of the reads, quality check, read trimming and adapter removal, 
*E. cicutarium* genome download and indexing, alignment to genome, and
read count summarization.

The script has comments on which code chunks makes which specific part. 

### 02-ecicHerb_DiffGeneExpr_analysis.R

This R script performs the differential gene expression analysis, mainly
using the library DESeq2 (Love *et al.*, 2014). There are chunkss of 
code that will load and normalize the read counts generated by the 
script \#01, fit models to the counts, generate tests for differential
expression, and visualize generated differentially expressed gene (DEG) 
lists with plots such as NMDS or Volcano plots. The script will generate 
some descriptive statistics, whose results are already commented on the 
side of each relevant command. 

NOTE: an acclaration about the interpretation of the model factors is
commented before the differential gene expression analysis (DGEA) chunk.

### 03-ecicHerb-enrichGOterm_analysis.R

This R script performs GO term enrichment analysis with topGO (Alexa 
*et al.* 2009). It loads the GO term universe, and performs Fisher Exact 
Tests for all the DEG lists generated by the script \#02. The script has
functions to represent plots. In the comments, instruction to analyze 
massive enriched GO term lists with ReViGO (Supek *et al.* 2011), an 
online tool to semantically remove redundant GO terms and keep the more
representatives in each ontology.

### 04-ecicHerb_aux_script_stats_and_Fig4.R

This R script generates the Figure 4 as it is in the paper, plus some
statistics described in the Results section.

### 05-ecicHerb_aux_script_SuplFig.R

This R script generates the Supplemental Figure with the analysis of all
RNA-seq samples, comparing all control vs. all demethylated samples, 
independently of their herbivory treatment.

### src/adapters.fa

FASTA file with Illumina adapter nucleotide sequences, used by the 
RNA-seq script \#01.

### src/ecic_basenames.txt

Plain text file with the FASTQ file names used by the analysis, used by 
the RNA-seq script \#01.

### src/gff2gtf_rtracklayer_windows.R

Auxiliary R script to format the GFF/GTF file from *E. cicutarium* 
genome, used by the RNA-seq script \#01.
